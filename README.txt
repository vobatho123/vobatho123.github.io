# Free Fire Gaming Website

## Chỉnh sửa nhanh
- Mở `index.html` bằng trình soạn thảo văn bản.
- Đổi `YOUR GAMING NAME` thành tên game của bạn.
- Sửa dòng mô tả và các liên kết Facebook/TikTok nếu muốn.
- Ảnh mặc định nằm ở `assets/avatar.svg`. Muốn dùng ảnh riêng, tải ảnh lên thư mục `assets`, ví dụ `avatar.jpg`, rồi đổi `src="assets/avatar.svg"` thành `src="assets/avatar.jpg"`.

## Thêm nhạc HUSTLANG ALL DAY
Vì bài hát có bản quyền, gói này không kèm file nhạc. Hãy tự thêm file MP3 mà bạn có quyền sử dụng vào thư mục `assets` và đặt đúng tên:
`hustlang-all-day.mp3`

Trình phát đã bật `loop`, nên nhạc sẽ lặp lại khi hết. Trình duyệt thường chặn tự phát âm thanh; khách truy cập cần bấm Play lần đầu.

## Đưa lên GitHub Pages
1. Tạo một repository GitHub mới, chọn **Public**.
2. Tải toàn bộ nội dung trong thư mục này lên repository (đặc biệt là `index.html` và thư mục `assets`).
3. Mở **Settings → Pages**.
4. Trong **Build and deployment**, chọn **Deploy from a branch**.
5. Chọn branch `main`, folder `/(root)`, rồi nhấn **Save**.
6. Chờ GitHub triển khai. Địa chỉ thường có dạng `https://TEN-TAI-KHOAN.github.io/TEN-REPOSITORY/`.

Nếu trang chưa hiện ngay, đợi vài phút rồi tải lại.
